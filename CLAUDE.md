# Project instructions

The rules in [ARCHITECTURE_PRINCIPLES.md](docs/ARCHITECTURE_PRINCIPLES.md) are binding. Check every
change against its checklist.

## Working mode

- Work one milestone of [ROADMAP.md](docs/ROADMAP.md) at a time. Each milestone is reviewed
  before the next one starts.

## Vocabulary

Use these terms everywhere: schema, Go, Python, SQL and dashboards. See ADR-001.

- **price**: quote currency per unit of base (USD per BTC).
- **quantity**: base units (BTC). Never `amount`, `size`, `volume` or `qty`. Translate exchange
  names at the adapter boundary.
- **notional**: quote-currency value, price × quantity (USD).
- All three are exact decimals: decimal strings on the wire, never floats.

## Generated code

- `services/ingestor/internal/gen/` and `services/detector/src/arbscanner/` are generated by
  `make gen` from `proto/`. Never edit them by hand: change the `.proto`, run `make gen`, and
  commit the result together with the schema change.
- Schema decisions and the subject convention are in
  [ADR-001](docs/adr/0001-protobuf-contracts.md). A change to the reference messages in
  `services/ingestor/internal/contract/golden_test.go` needs `go test ./internal/contract -update`
  and the matching change in `services/detector/tests/unit/test_contracts.py`.

## Commits

- Subjects follow [Conventional Commits](https://www.conventionalcommits.org):
  `<type>(<scope>): <description>`, for example `feat(ingestor): add Kraken order book adapter`.
- Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`,
  `revert`. Append `!` after the type or scope for a breaking change.
- Scope is optional and names the area touched: `ingestor`, `detector`, `deploy`, `ci`, `proto`.
  Leave it out when a change spans several areas.
- Description: English, imperative mood, lowercase, no trailing period. Whole subject at most
  72 characters.
- `scripts/check-commits.sh` enforces this in CI and in the local `commit-msg` hook
  (`make hooks`). Run `make check-commits` before pushing.
